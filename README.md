This project is about developing a chat app such as the whatsapp, in this app the system will first ask the user to enter their details to register, after the registration process has been successful, the user will therefore asked to enter their username and password, after logging in the system then asks the user how many messages would they like to send. Right after, user will be asked to enter the recipient's number to type in the message, the user will therefore choose whether they want to send the message, store it or disregard.
